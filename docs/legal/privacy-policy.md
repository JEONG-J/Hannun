# 한눈(Hannun) 개인정보 처리방침

- 시행일: 2026년 8월 9일
- 최종 수정일: 2026년 8월 9일

한눈(Hannun, 이하 "앱")은 개인 개발자가 만든 자산관리 iOS 앱입니다.
**앱은 별도의 서버를 운영하지 않으며, 개발자는 이용자의 어떠한 개인정보도 수집·전송·보관하지 않습니다.**

---

## 1. 한눈이 수집하지 않는 것

앱은 다음을 **일절 수집하지 않습니다.**

- 이름, 이메일, 전화번호, 생년월일 등 신원 정보
- 위치 정보, 연락처, 사진, 캘린더, 건강 데이터
- 광고 식별자(IDFA), 기기 식별자
- 사용 기록·행동 로그 등 분석(Analytics) 데이터
- 크래시 리포트

앱에는 광고 SDK, 분석 SDK, 추적(Tracking) 기능이 **포함되어 있지 않습니다.**
App Store 개인정보 보호 레이블 기준으로도 "데이터가 수집되지 않음"에 해당합니다.

## 2. 이용자가 입력한 정보와 저장 위치

이용자가 앱에 직접 입력한 아래 정보는 **이용자의 기기와 이용자 본인의 iCloud 계정 안에만** 저장됩니다.

| 정보 | 저장 위치 |
|---|---|
| 보유 자산(종목명, 티커, 수량, 평균 매입가, 통화) | 기기 내부 저장소 + 이용자 iCloud 개인 데이터베이스 |
| 입금·출금 기록 | 동일 |
| 자산 스냅샷(자산 추이 그래프용) | 동일 |
| 매매일지(제목, 본문, 연결 종목) | 동일 |
| 앱 설정값(표시 통화 등) | 기기 내부 저장소 |
| 한국투자증권 Open API 앱키·시크릿 | 기기 키체인 + iCloud 키체인 |

iCloud 동기화는 Apple의 **CloudKit 개인 데이터베이스(private database)** 를 사용합니다.
이 영역은 이용자 본인의 Apple 계정에 귀속되며, **개발자는 그 내용에 접근할 수 없습니다.**
동기화 시점을 알리기 위해 Apple이 제공하는 백그라운드 알림이 사용될 수 있으며, 이 알림에는
자산 내용이 담기지 않습니다.

iCloud 동기화를 원하지 않으면 iOS **설정 앱 → Apple 계정 → iCloud → 앱별 동기화**에서
한눈을 끌 수 있습니다. 이 경우 데이터는 해당 기기에만 저장됩니다.

## 3. 외부 서비스와의 통신

앱은 시세·환율 조회를 위해 아래 두 곳에만 네트워크 요청을 보냅니다.

| 서비스 | 용도 | 전송되는 정보 |
|---|---|---|
| 한국투자증권(KIS) Open API<br>`openapi.koreainvestment.com` | 국내/해외 주식·ETF 시세, 환율, 벤치마크 지수 | 이용자가 등록한 **앱키·앱시크릿**(인증용), 조회 대상 **종목코드** |
| 업비트 공개 API<br>`api.upbit.com` | 코인 시세, 비트코인 벤치마크 | 조회 대상 **코인 티커** (인증 불필요) |

- 위 요청에는 **보유 수량, 평균 매입가, 총자산, 입출금 기록, 매매일지가 포함되지 않습니다.**
  앱은 "무엇을 얼마나 갖고 있는지"가 아니라 "이 종목의 현재 가격"만 물어봅니다.
- 앱키·시크릿은 이용자가 한국투자증권에서 직접 발급받아 앱에 입력한 값이며,
  해당 API 인증 목적 외에는 사용되지 않고 개발자에게 전송되지 않습니다.
- 각 서비스의 개인정보 처리는 해당 사업자의 방침을 따릅니다.
  - 한국투자증권: https://securities.koreainvestment.com
  - 업비트: https://upbit.com/service_center/guide

## 4. Apple Intelligence(온디바이스 AI)

매매일지 초안 작성 기능은 Apple의 **온디바이스 파운데이션 모델**을 사용합니다.
입력한 내용은 **기기 안에서만 처리되며 외부 서버로 전송되지 않습니다.**
개발자를 포함한 제3자는 그 내용을 볼 수 없습니다.

## 5. 제3자 제공 및 위탁

앱은 이용자의 정보를 제3자에게 제공하거나 처리를 위탁하지 않습니다.
개발자가 보관하는 이용자 정보 자체가 없으므로 판매·공유·광고 활용도 발생하지 않습니다.

## 6. 보유 기간과 삭제 방법

데이터는 이용자가 삭제할 때까지 이용자의 기기와 iCloud에 보관됩니다.
개발자가 별도로 보관하는 사본은 없습니다.

- **앱 데이터 삭제**: 기기에서 앱을 삭제합니다.
- **iCloud 사본 삭제**: 설정 앱 → Apple 계정 → iCloud → 저장 공간 관리 → 한눈 → 삭제
- **앱키 삭제**: 앱의 설정 화면에서 등록한 앱키를 삭제하면 키체인에서 제거됩니다.
  iCloud 키체인 동기화를 켠 경우 다른 기기에서도 함께 삭제됩니다.

## 7. 이용자의 권리

앱의 모든 데이터는 이용자의 기기와 iCloud 계정에 있으므로, 이용자는 언제든지 직접
열람·수정·삭제할 수 있습니다. 개발자가 보관하는 정보가 없어 별도의 열람·정정 청구 절차는
필요하지 않습니다.

## 8. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동으로부터 어떠한 정보도 수집하지 않습니다.

## 9. 접근 권한

앱은 시세 조회를 위한 **네트워크 접근**만 사용합니다.
카메라, 마이크, 위치, 연락처, 사진, 알림 등 별도 권한을 요구하지 않습니다.

## 10. 방침 변경

이 방침이 변경되면 이 페이지의 내용을 갱신하고 상단의 최종 수정일을 함께 수정합니다.
중요한 변경이 있을 경우 앱 업데이트 설명을 통해 안내합니다.
